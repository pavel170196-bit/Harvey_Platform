Что это

Harvey (HM) — модульная ИИ-платформа с разделением ответственности: языковая модель формулирует и объясняет, детерминированные алгоритмы Python проверяют числа и критерии. Модель не может «сочинить» балл.

Модули

| Модуль | Роль |
|---|---|
| EDUMIND | Проверка работ по критериям ФИПИ, планы уроков, тесты |
| PMMIND | Расчёты и графики для физики и математики |
| INDMIND | Реестр оборудования, учёт отказов, предиктивная аналитика |
| ASTROMIND | Астрономия (Skyfield), МКС, карта звёздного неба |
| CHESSMIND | Шахматы (игра против базы партий + Stockfish) |
| LITMIND | Анализ литературных произведений |
| LAWMIND | Разбор правовых ситуаций |
| FINMIND | Финансовые расчёты |

Архитектура

ВЫ → СЕКРЕТАРЬ (Cerebrum) → ДИСПЕТЧЕР → [ МОДУЛИ ] → СЕКРЕТАРЬ → ВЫ

Секретарь решает, кто нужен. Диспетчер вызывает модули параллельно. Модули не общаются друг с другом — только через диспетчера. Вы получаете один ответ.
